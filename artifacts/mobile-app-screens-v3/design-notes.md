# Mobile information architecture

The five primary screens use normal phone proportions. Secondary desktop information belongs in mobile detail views and sheets rather than being compressed into the overview. These destinations are a design specification; only the five main screenshots have been rendered.

## Visual system
White canvas, pale gray grouped surfaces, near-black text, the existing Ocean blue accent. Native SF Pro scale, large page headings, 17-point list titles, readable 13-point metadata, touch targets of at least 44 points, fixed five-tab navigation. Single task hierarchy on each screen.

## Desktop feature placement

| Page | Visible in the mockup | Secondary destination |
| --- | --- | --- |
| My Drive | Cloud/Backup/Sync switch, search, modified sort, filter control, file and folder names, file sizes and dates, New, storage, account | New opens Upload files/New folder. Filters contain type, date, sort direction, folders-first, system files and list/grid choices. Row menu contains open/download (ZIP for folders), send/share, rename/move, favorites, details, version history and trash. Item details include exact dates and folder metadata. Backup location offers archive browsing and disconnection; Sync location offers source status, copy to cloud and removal. Selection mode offers bulk actions. Pagination becomes load-more at the end of the list. |
| Sync | Source device, Folders/Activity, active transfer/progress/pause, queued changes, folder counts/status, Add, conflict entry, invitations and help | Folder details contain local location, contents, last synced, queued changes, exclusions, open-local action and management. Overflow contains global pause/resume. Folder actions contain pause/resume, sharing, change location, activity, exclusions, details, remove. Activity contains operation, file, folder, byte/percentage progress, state, errors and recent completion times. Shared with you includes sender, two-way sync, accept/reject and folder selection. Conflict detail includes preserved versions and resolution. Help retains all desktop explanations. |
| Backups | Archives/History/Restores, source device, folders/counts/sizes, most recent backup, version and restore entries, folder management | Folder archive opens breadcrumb file browser with name, size and modified date. File opens versions with number, latest marker, saved date, size, restore and export guidance. History includes trigger, state, file count, size, start/end times, errors and files covered. Restores includes requested/completed dates, state, pending-source explanation and errors. Manage folder includes local path, one-hour automatic backup rule, source-computer options/back-up-now, disconnection and preservation of deleted local files. |
| Trash | File name, size, modified time, count, select, Empty, restore/permanent-delete sheet | Delete confirmation explains loss of version history. Empty confirmation covers all pages and temporary retention for sent transfers. Selection offers batch operations. More items load at the end of the list. |
| Settings | Account/storage, appearance, color theme, custom colors, connected computer, notifications, diagnostics and sign out | Appearance contains Light/Dark/System. Theme contains Harbor/Ocean/Forest/Violet/Sunset with descriptions and preset reset explanation. Custom colors contains Accent/Background/Cards/Sidebar/Borders, descriptions, swatches, hex values, per-field reset, separate light/dark values, reset-all and account save/retry state. Computer settings explain background sync. Notifications contains system permissions, test notification, notification settings and failure feedback, scoped to the computer. |

Other desktop navigation (Received, Sent, Favorites, Devices and Storage) belongs in the account/workspace destination reached through the avatar. Computer-specific controls are scoped to the selected source computer; these mockups do not establish that remote-control functionality currently exists.
